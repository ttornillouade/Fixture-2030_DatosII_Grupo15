# Evidencia obligatoria

1. `docker compose ps`.
2. `nodetool status`.
3. `SHOW VERSION`.
4. `DESCRIBE KEYSPACE fixture2030_comments`.
5. Consulta del feed por partido.
6. Consulta por usuario.
7. Segunda carga de muestra sin duplicados lógicos.
8. Archivo de rendimiento real generado por `scripts/carga_volumen.sh`.

Registrar además fecha, modelo/CPU del equipo y memoria asignada a Docker.
